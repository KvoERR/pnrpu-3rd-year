# Реализация перетаскивания точек мышью (Drag Points)

## Цель
Позволить пользователю перетаскивать точки фигур на canvas с помощью мыши (зажать ЛКМ и двигать).

## Текущее состояние
- Фигуры состоят из точек (`ShapePoint`) с координатами `Position`
- Каждая точка имеет `PointViewModel` с свойствами `X` и `Y`
- Уже есть `VertexSelectionBehavior` — выделяет точку при клике
- Уже есть кнопки MoveLeft/Right/Up/Down для перемещения точек
- **Нет** drag-and-drop для точек

## План реализации

### 1. Создать `PointDragBehavior.cs` в `ViewModels/`
Attached Behavior для перетаскивания точек на Canvas.

**Логика:**
- Использовать Attached Property `IsDraggable` на `Ellipse` (точке)
- При `MouseLeftButtonDown` на точке — начать drag:
  - Запомнить начальную позицию мыши и координаты точки
  - Подписаться на `MouseMove` и `MouseLeftButtonUp`
- При `MouseMove` (если drag активен):
  - Вычислить дельту смещения мыши
  - Применить дельту к `PointViewModel.X` и `PointViewModel.Y`
- При `MouseLeftButtonUp` — завершить drag, отписаться от событий

**Ключевые моменты:**
- Использовать `e.GetPosition(Canvas)` для получения координат мыши относительно canvas
- Дельта: `deltaX = currentMouseX - startMouseX`, аналогично для Y
- Обновлять `PointViewModel.X/Y` — это автоматически обновит `ShapePoint.Position` через backing model
- Не конфликтовать с `VertexSelectionBehavior` — drag начинается после нажатия (не сразу при клике)

### 2. Обновить `MainWindow.xaml`
Добавить `local:PointDragBehavior.IsDraggable="True"` к эллипсам точек в шаблоне `ShapeTemplate`.

### 3. Обновить `VertexSelectionBehavior.cs`
Убедиться, что выделение точки и drag не конфликтуют:
- `VertexSelectionBehavior` — срабатывает при `MouseLeftButtonDown` (выделение)
- `PointDragBehavior` — срабатывает при `MouseMove` после нажатия (drag)
- Оба должны работать вместе: клик выделяет, drag перемещает

## Файлы для изменения

| Файл | Действие |
|------|----------|
| `ViewModels/PointDragBehavior.cs` | **Создать** — новый Attached Behavior для drag |
| `Views/MainWindow.xaml` | **Изменить** — добавить `IsDraggable="True"` к эллипсам точек |

## Детали реализации PointDragBehavior

```
Attached Property: IsDraggable (bool)

OnIsDraggableChanged:
  - При true: подписаться на MouseLeftButtonDown на Ellipse
  - При false: отписаться

MouseLeftButtonDown:
  - Запомнить startMousePosition (относительно Canvas)
  - Запомнить startPointX, startPointY (из PointViewModel)
  - Подписаться на MouseMove и MouseLeftButtonUp
  - Установить CaptureMouse на эллипсе

MouseMove:
  - Если drag активен:
    - deltaX = currentMouseX - startMouseX
    - deltaY = currentMouseY - startMouseY
    - pointVm.X = startPointX + deltaX
    - pointVm.Y = startPointY + deltaY

MouseLeftButtonUp:
  - Завершить drag
  - Отписаться от MouseMove и MouseLeftButtonUp
  - ReleaseMouseCapture
```

## Тестирование
- Добавить фигуру (треугольник, линию, точку)
- Кликнуть на точку — она должна выделиться (красная рамка)
- Зажать ЛКМ на точке и двигать мышь — точка должна следовать за курсором
- Отпустить кнопку — точка должна остаться на месте
- Проверить, что линии сохраняют связь с точками при перемещении
- Проверить, что свойства точки в правой панели обновляются
