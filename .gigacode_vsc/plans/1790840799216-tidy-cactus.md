# RSA File Encryption — Plan

## Цель
Выполнить шифрование текстового файла методом RSA, используя простые числа p и q разрядностью не менее 16 цифр.

## Изменения

### 1. Создать тестовый текстовый файл `input.txt`
- Небольшой файл с текстом (UTF-8) для демонстрации шифрования.

### 2. Обновить `main.py`
- **Заменить p и q на 16-значные простые числа:**
  - `p = 1000000000000003` (16 цифр, простое)
  - `q = 1000000000000037` (16 цифр, простое)
  - `n ≈ 10³²`, bit_length ≈ 106, block_size = 13 байт.
- **Добавить функции для работы с файлами:**
  - `encrypt_file(input_path, output_path, e, n)` — читает файл в бинарном режиме, шифрует каждый блок, записывает зашифрованные числа (через запятую) в файл.
  - `decrypt_file(input_path, output_path, d, n)` — читает зашифрованный файл, расшифровывает, записывает исходный текст в файл.
- **Обновить блок `__main__`:**
  - Шифровать `input.txt` → `encrypted.txt`.
  - Расшифровывать `encrypted.txt` → `decrypted.txt`.
  - Сравнивать `input.txt` и `decrypted.txt` — должны совпасть.

### 3. GUI не изменять
- Существующий GUI с текстовым полем остаётся без изменений.

## Примечания
- Для больших файлов можно было бы использовать гибридное шифрование, но по условию задачи требуется чистый RSA.
- Файл шифруется в бинарном режиме, зашифрованный результат хранится как текст (числа через запятую).
