# План привязки gui.py к main.py

## Цель
Обеспечить запуск GUI из `main.py` и расширить функционал GUI: импорт из файла, сохранение результата, информационное поле.

## План

### 1. main.py — уже изменён
- `import sys` добавлен
- Блок `__main__` обёрнут в `run_demo()`
- Добавлен флаг `--gui`: `python main.py --gui` запускает GUI

### 2. gui.py — добавить импорт из файла
- Добавить кнопку "Импорт из файла" над полем ввода текста
- При нажатии — `filedialog.askopenfilename()` для выбора файла
- Содержимое файла загружается в `self.text_entry`

### 3. gui.py — добавить сохранение результата
- Добавить кнопку "Сохранить результат" рядом с кнопками шифрования/расшифрования
- При нажатии — `filedialog.asksaveasfilename()` для выбора пути
- Содержимое `self.result_text` записывается в выбранный файл

### 4. gui.py — валидация разрядности p и q (≥ 16 бит)
- В `_validate_primes()` добавить проверку: `p.bit_length() >= 16` и `q.bit_length() >= 16`
- 16 бит в двоичной = число ≥ 2^15 = 32768
- Если меньше — raise CipherError с пояснением: "Разрядность p = N бит, нужно ≥ 16"
- Обновить подписи полей: "p (≥16 бит)" и "q (≥16 бит)"

### 5. gui.py — добавить информационное поле
- Добавить `ttk.Label` внизу окна
- Показывать статус: "Готово", "Шифрование...", "Ошибка: ..."
- Обновлять при каждом действии

### 6. Обновить layout
Новая структура окна (примерно 600x580):
```
row 0: Текст:
row 1: Text widget (текст)
row 2: Кнопка "Импорт из файла"
row 3: p и q фрейм
row 4: Кнопки "Зашифровать", "Расшифровать", "Сохранить результат"
row 5: Результат:
row 6: Text widget (результат)
row 7: Информационное поле (статус)
```

## Итоговое поведение
- `python main.py` — текущий демо-режим (шифрование файла)
- `python main.py --gui` — запуск GUI
- `python gui.py` — запуск GUI
- GUI: импорт из файла → шифрование/расшифрование → сохранение результата → статус
