# План: Разделение фигур на отдельные точки и линии

## Цель
Каждая фигура становится группой отдельных элементов — точек и линий. Каждый элемент имеет собственные свойства (цвет, толщина, видимость), которые можно менять независимо.

## Текущая архитектура
- `ShapeItem` (базовый) → `PointShape`, `LineShape`, `TriangleShape`
- Каждый `ShapeItem` хранит `Point[] Points` и общие свойства `Fill`, `Stroke`, `StrokeThickness`
- UI рисует `Polyline` + кружки через `ItemsControl`

## Новая архитектура

### 1. Models — Элементы

**1.1. Создать `GraphicElement` (базовый абстрактный класс)**
- `Id`, `Type` (Point / Line), `IsVisible`
- `Stroke` (Brush), `StrokeThickness` (double) — для точек и линий
- `Fill` (Brush) — только для точек (замкнутых)
- `Points` (Point[]) — локальные координаты
- `TransformMatrix` (Matrix) — трансформация

**1.2. Создать `PointElement : GraphicElement`**
- `Points = new Point[] { new Point(0, 0) }` — одна точка
- `StrokeThickness = 0` — у точки нет границы, только заливка
- `Fill` по умолчанию — красный

**1.3. Создать `LineElement : GraphicElement`**
- `Points = new Point[] { start, end }` — две точки
- `StrokeThickness = 3` по умолчанию
- `Fill = Transparent` — линия не заливается

**1.4. Создать `ShapeGroup : GraphicElement`** (или просто контейнер)
- Хранит `ObservableCollection<GraphicElement> Elements` — список точек и линий
- Общие свойства группы (позиция, поворот, масштаб) — применяются ко всем элементам через TransformMatrix
- Но каждый элемент имеет СВОИ Stroke, Fill, StrokeThickness

### 2. Models — Фигуры (переделать)

**2.1. Переделать `PointShape`**
- Теперь это обёртка над `ShapeGroup`, содержащая 1 `PointElement`

**2.2. Переделать `LineShape`**
- Теперь это обёртка над `ShapeGroup`, содержащая 1 `LineElement`

**2.3. Переделать `TriangleShape`**
- Теперь это обёртка над `ShapeGroup`, содержащая:
  - 3 `PointElement` (вершины)
  - 3 `LineElement` (стороны)

### 3. ViewModels

**3.1. Создать `GraphicElementViewModel : INotifyPropertyChanged`**
- Обёртка над `GraphicElement`
- Свойства: `Id`, `Type`, `Stroke`, `Fill`, `StrokeThickness`, `IsVisible`, `TransformedPoints`
- Привязка UI к отдельным элементам

**3.2. Переделать `ShapeViewModel`**
- Содержит `ObservableCollection<GraphicElementViewModel> Elements`
- Общие свойства группы: `X`, `Y`, `RotationAngle`, `ScaleFactor`
- Каждый элемент доступен отдельно через `Elements[i]`

### 4. XAML — Шаблоны

**4.1. Новый `DataTemplate` для `GraphicElementViewModel`**
- Точки: `Ellipse` с `Fill` и `Width/Height` из свойств элемента
- Линии: `Polyline` с `Stroke` и `StrokeThickness` из свойств элемента

**4.2. Обновить `ShapeTemplate`**
- Вместо одного `Canvas` с общими свойствами → `ItemsControl` для `Elements`
- Каждый элемент рендерится по своему шаблону

### 5. MainViewModel

**5.1. Обновить `AddShape`**
- Создаёт `ShapeGroup` с нужными `GraphicElement` внутри

**5.2. Обновить `ShapeDto`**
- Сериализация: каждый элемент группы сохраняется отдельно с своими свойствами
- Десериализация: восстанавливает элементы с индивидуальными свойствами

### 6. Файлы для изменения
