# Plan: 2D манипулятор с колёсной базой

## Цель
Преобразовать текущий 3D-манипулятор в 2D-модель с возможностью движения основания влево-вправо по оси X.

## Изменения

### 1. Убрать 3D, перейти на 2D
- Удалить `projection='3d'` из осей
- Заменить на обычный 2D `plt.subplots()`
- Удалить `rot_z`, `rot_y` — заменить на 2D-вращения через `cos/sin`
- Удалить `shift` с 4x4 матрицами — использовать простые 2D-координаты

### 2. 2D кинематика манипулятора
- Основание движется по оси X (параметр `base_x`)
- Два сустава: угол плеча (`theta1`) и угол локтя (`theta2`)
- Вычислять координаты звеньев через прямую кинематику в 2D:
  - `x0 = base_x, y0 = 0`
  - `x1 = x0 + L1 * cos(theta1), y1 = y0 + L1 * sin(theta1)`
  - `x2 = x1 + L2 * cos(theta1 + theta2), y2 = y1 + L2 * sin(theta1 + theta2)`

### 3. Управление клавишами
- `← →` — движение основания (колёса)
- `↑ ↓` — вращение плеча (theta1)
- `A/F` или `D/G` — вращение локтя (theta2)
- `R` — сброс в начальное положение

### 4. Отрисовка
- 2D линии для звеньев (два слоя: внешний/внутренний для толщины)
- Точки сочленений (оранжевые)
- Конечный эффектор (красный)
- Подпись текущих углов и позиции основания
- Подсказка по управлению

### 5. Анимация
- `FuncAnimation` с `interval=50`
- Обновление координат и перерисовка линий/точек в `update()`
