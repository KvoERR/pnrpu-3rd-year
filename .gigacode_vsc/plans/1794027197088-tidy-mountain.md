# План: Фрактал Мандельброта

## Цель
Создать Python-программу, визуализирующую множество Мандельброта с настраиваемым количеством итераций.

## Реализация
1. Один файл `mandelbrot.py` с использованием `numpy` + `matplotlib`.
2. Параметр `--iterations` (по умолчанию 100) через `argparse`.
3. Визуализация через `matplotlib.pyplot.imshow` с colormap `viridis`.
4. Запуск: `python mandelbrot.py --iterations 200`.
