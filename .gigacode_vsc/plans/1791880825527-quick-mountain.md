# План: Приложение «Замкнутый кубический сплайн»

## Цель
Программа с 2D плоскостью координат, куда пользователь кликает для добавления точек. По точкам строится замкнутый кубический сплайн (кривая проходит через все точки и замыкается в петлю с C2-гладкостью).

## Архитектура
Один файл `main.py` на matplotlib с callback-механизмом для обработки кликов.

### 2. Алгоритм замкнутого кубического сплайна
- Параметризация точек по кумулятивному расстоянию ( chord-length )
- Для каждой координаты (x и y отдельно) строим замкнутый кубический сплайн:
  - Решаем систему линейных уравнений для вторых производных M[i]
  - Для замкнутого сплайна: M[0] = M[n-1], M'[0] = M'[n-1], M''[0] = M''[n-1]
  - Система n×n с циклической структурой (решается обобщённым методом прогонки)
- Интерполяция между точками по найденным коэффициентам

### 3. GUI на matplotlib
- Canvas с `ax.plot()` для осей и сетки
- `fig.canvas.mpl_connect('button_press_event', on_click)` — обработка кликов
- Отображение точек кружками, сплайн — плавной кривой
- Кнопки/горячие клавиши:
  - **ЛКМ** — добавить точку
  - **Right-click / Escape** — завершить ввод и построить сплайн
  - **R** — очистить всё и начать заново
  - **Backspace/Delete** — удалить последнюю точку
- Автомасштабирование при добавлении точек

### 4. Визуальное оформление
- Оси координат с делениями
- Сетка
- Точки — красные кружки с номерами
- Сплайн — синяя плавная кривая
- Координаты точек отображаются при наведении/в статусной строке
