# План: Реализация шифрования Эль-Гамаля

## Требования
- Метод шифрования: Эль-Гамаль
- Длина сообщения: ≥ 256 символов
- **p** (простое число, модуль) — ≥ 20 десятичных цифр
- **g** (генератор) — простое число, ≥ 12 десятичных цифр
- **x** (закрытый ключ) — простое число, ≥ 12 десятичных цифр
- **k** (временный ключ) — ≥ 20 десятичных цифр

## План реализации

### 1. Добавить функции Эль-Гамаля в `main.py`

#### 1.1. Функция генерации простого числа с заданной разрядностью в десятичных цифрах
- `generate_prime_decimal_digits(num_digits)` — генерирует простое число с ≥ `num_digits` десятичными цифрами (используя существующую `generate_prime(bits)` или свою реализацию через `math.ceil(num_digits * math.log2(10))` бит)

#### 1.2. Функция проверки простоты числа
- Использовать существующую `is_prime_miller_rabin`

#### 1.3. Функция поиска примитивного корня (генератора) для простого p
- `find_generator(p)` — находит наименьший примитивный корень mod p
- Алгоритм: разложить p-1 на простые множители, проверить условие `g^((p-1)/q) mod p ≠ 1` для каждого простого множителя q

#### 1.4. Функция генерации ключей Эль-Гамаля
- `generate_elgamal_keys(p, g, x)` — возвращает `(p, g, y)` где `y = g^x mod p` (публичный ключ)
- p ≥ 20 цифр, g — простое ≥ 12 цифр, x — простое ≥ 12 цифр

#### 1.5. Функция шифрования
- `encrypt_elgamal(text, p, g, y)` — шифрует текст методом Эль-Гамаля
- Текст разбивается на блоки, каждый блок < p
- Для каждого блока m: генерируем k (≥ 20 цифр), вычисляем `(c1, c2) = (g^k mod p, m * y^k mod p)`
- Возвращаем список пар `(c1, c2)`

#### 1.6. Функция расшифрования
- `decrypt_elgamal(ciphertext_pairs, x, p)` — расшифровывает текст
- Для каждой пары `(c1, c2)`: `m = c2 * (c1^x)^(-1) mod p`
- Собираем блоки обратно в текст

#### 1.7. Вспомогательные функции преобразования текст ↔ блоки
- `_text_to_blocks_elgamal(text, p)` — текст → список целых чисел (каждое < p)
- `_blocks_to_text_elgamal(blocks)` — список целых чисел → текст
