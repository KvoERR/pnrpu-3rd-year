# План: Базовое WPF приложение с MVVM

## Цель
Создать базовое WPF приложение с паттерном MVVM, готовое к расширению.

## Структура проекта

```
KostyaBank/
├── KostyaBank.sln
├── KostyaBank/
│   ├── KostyaBank.csproj
│   ├── App.xaml
│   ├── App.xaml.cs
│   ├── Models/
│   │   └── Account.cs
│   ├── ViewModels/
│   │   ├── ViewModelBase.cs
│   │   └── MainWindowViewModel.cs
│   ├── Views/
│   │   ├── MainWindow.xaml
│   │   └── MainWindow.xaml.cs
│   └── Converters/
│       └── BoolToVisibilityConverter.cs
```

## Архитектура

### 1. Проект (.csproj)
- .NET 8.0 WPF
- Без XAML компилятора (или с ним)
- Корневой неймспейс: `KostyaBank`

### 2. Models/Account.cs
- Модель данных — счёт банкомата
- Свойства: Balance (decimal), IsEnabled (bool)
- Простая POCO-модель

### 3. ViewModels/ViewModelBase.cs
- Базовый класс для ViewModel
- Реализация `INotifyPropertyChanged`
- Метод `SetProperty<T>()` для обновления свойств

### 4. ViewModels/MainWindowViewModel.cs
- Главная ViewModel
- Свойства: Balance, AccountStatus
- Команды: DepositCommand, WithdrawCommand (через `ICommand`)
- Реализация `RelayCommand` / `DelegateCommand`

### 5. Views/MainWindow.xaml
- Окно с привязкой к MainWindowViewModel
- Элементы UI:
  - Отображение баланса
  - Кнопки "Пополнить" / "Снять"
  - Поле ввода суммы
  - Статус-сообщение
- DataContext задаётся через `d:DataContext` для дизайна и через код

### 6. Views/MainWindow.xaml.cs
- Минимальный code-behind (без логики)
- Установка DataContext в конструкторе

### 7. Converters/BoolToVisibilityConverter.cs
- Стандартный конвертер для привязки bool → Visibility

## Пример функционала
Приложение имитирует базовый интерфейс банкомата:
- Показывает текущий баланс
- Позволяет пополнить/снять средства
- Валидирует ввод (нельзя снять больше баланса, отрицательные суммы)
- Показывает статусные сообщения

## Шаги реализации
1. Создать solution и проект через `dotnet new wpf`
2. Реорганизовать структуру папок (Models, ViewModels, Views, Converters)
3. Реализовать ViewModelBase с INotifyPropertyChanged
4. Реализовать RelayCommand
5. Реализовать MainWindowViewModel с командами
6. Создать модель Account
7. Создать MainWindow.xaml с привязками
8. Настроить App.xaml для регистрации главного окна
9. Добавить конвертер BoolToVisibility
10. Проверить сборку (`dotnet build`)
