# План: Переделка GUI на 2 самостоятельные вкладки

## Цель
Перестроить интерфейс так, чтобы было ровно 2 вкладки:
1. **Шифровка** — на вход: текст, p, q
2. **Дешифровка** — на вход: текст, d, n

## Текущее состояние
- `gui.py`: общие элементы (текст, p, q) сверху, затем Notebook с двумя вкладками, которые дублируют эти же поля
- `main.py`: функции `encrypt(text, e, n)`, `decrypt(ciphertext, d, n)`, `generate_keys(p, q)` → `(e, n, d)`

## Изменения в `gui.py`

### Убрать
- Общие элементы сверху: `text_entry`, `import_btn`, `p_frame` (p/q entry), `generate_btn`, `info_label` внизу
- Дублирование полей внутри вкладок

### Структура Notebook (2 вкладки)

#### Вкладка "Шифровка"
```
Текст: [Text widget]
p: [Entry]    q: [Entry]
[🔑 Генерировать p и q]  [Зашифровать]
Результат: [Text widget, disabled]
```
- Метод `encrypt()`: читает текст/p/q из этой вкладки, вызывает `_validate_primes_from_tab()` → `generate_keys(p,q)` → `encrypt(text, e, n)` → выводит результат

#### Вкладка "Дешифровка"
```
Шифротекст: [Text widget]
d: [Entry]   n: [Entry]
[Расшифровать]
Результат: [Text widget, disabled]
```
- Метод `decrypt()`: читает шифротекст/d/n из этой вкладки, валидирует d и n (целые числа), вызывает `decrypt(ciphertext, d, n)` → выводит результат

### Новые/изменённые методы
- `_validate_primes()` → `_validate_primes_for_encrypt()` — читает p, q из вкладки шифровки, генерирует e, n, d
- `_validate_decrypt_inputs()` — читает d, n из вкладки дешифровки, проверяет что это целые числа > 0
- `encrypt()` — переносит логику в контекст вкладки шифровки
- `decrypt()` — переносит логику в контекст вкладки дешифровки
- `generate_primes()` и `import_file()` остаются как есть, но привязаны к полям вкладки шифровки

## Изменения в `main.py`
Не требуются.

## Итог
Чистый интерфейс с двумя независимыми вкладками, каждая со своими полями ввода.
