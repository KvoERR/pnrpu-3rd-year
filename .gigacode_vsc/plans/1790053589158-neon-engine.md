# Унификация рендеринга фигур

## Цель
Заменить разнородный рендеринг (Ellipse/Line/Polygon) на единый — все фигуры рисуются как `Polygon` из `Point[]`.

## Изменения

### 1. MainWindow.xaml — DataTemplate

Заменить текущий `DataTemplate` (строки 23–124) на унифицированный:

```xml
<DataTemplate x:Key="ShapeTemplate">
    <Canvas>
        <!-- Универсальный полигон для всех фигур -->
        <Polygon Fill="{Binding Fill}"
                 Stroke="{Binding Stroke}"
                 StrokeThickness="{Binding StrokeThickness}"
                 StrokeLineJoin="Round"
                 Points="{Binding PointsCollection}"/>

        <!-- Для точки (1 вершина) — кружок поверх -->
        <Ellipse Width="8" Height="8" Fill="{Binding Fill}" Stroke="{Binding Stroke}" StrokeThickness="1">
            <Ellipse.Style>
                <Style TargetType="Ellipse">
                    <Setter Property="Visibility" Value="Collapsed"/>
                    <Setter Property="Canvas.Left" Value="{Binding PointX}"/>
                    <Setter Property="Canvas.Top" Value="{Binding PointY}"/>
                    <Style.Triggers>
                        <DataTrigger Binding="{Binding Type}" Value="Point">
                            <Setter Property="Visibility" Value="Visible"/>
                        </DataTrigger>
                    </Style.Triggers>
                </Style>
            </Ellipse.Style>
        </Ellipse>

        <!-- Рамка выделения -->
        <Rectangle Stroke="Blue" StrokeThickness="2"
                   StrokeDashArray="4,2" Fill="Transparent"
                   Visibility="{Binding IsSelected, Converter={StaticResource BoolToVisibility}}">
            <Rectangle.Style>
                <Style TargetType="Rectangle">
                    <Setter Property="Width" Value="{Binding Bounds.Width}"/>
                    <Setter Property="Height" Value="{Binding Bounds.Height}"/>
                    <Setter Property="Canvas.Left" Value="{Binding Bounds.X}"/>
                    <Setter Property="Canvas.Top" Value="{Binding Bounds.Y}"/>
                </Style>
            </Rectangle.Style>
        </Rectangle>
    </Canvas>
</DataTemplate>
```

Также удалить неиспользуемый `OffsetConverter` из `Window.Resources` (строка 20).

### 2. ShapeViewModel.cs — убрать лишние свойства

**Удалить** свойства (строки 43–47):
- `LineX1`, `LineY1`, `LineX2`, `LineY2`

**Оставить** (нужны для эллипса точки):
- `PointX`, `PointY`
- `TransformedPoints`
- `PointsCollection`

Обновить `NotifyTransformChanged()` — убрать упоминания `LineX1`-`LineY2`.

### 3. Shape.cs — без изменений

Типы `PointShape`, `LineShape`, `TriangleShape` остаются для сериализации и логики. Хранят `Point[]` — это уже правильно.

## Итог
- Все фигуры рисуются через один `<Polygon>` элемент
- Убраны DataTrigger-ветки из XAML
- Упрощён ShapeViewModel
- Сериализация не затрагивается
