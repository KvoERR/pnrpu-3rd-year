# План: Нейросеть для прогнозирования цены кофе

## Цель
Добавить в `ии/stock_forecast/main.py` MLP-модель для прогнозирования цены кофе на следующий день по историческим лагам.

## Что уже есть
- `main.py` — загрузка CSV, парсинг данных, создание лаговых признаков (`lag_1`, `lag_2`, `lag_3`, `lag_5`, `lag_10`, `lag_22`)
- `coffee_lags.csv` — 1150 строк с лагами (период ~2022-2024)
- Стилистика проекта: PyTorch, CLI-интерфейс (как в `ии/ml_numbers/main.py`)

## Что сделать

### 1. Добавить MLP-модель в `ии/stock_forecast/main.py`
- Класс `CoffeePriceMLP(nn.Module)` с архитектурой:
  - Input: 6 лагов (lag_1..lag_22)
  - Hidden: 64 → 32 нейронов, ReLU + Dropout(0.2)
  - Output: 1 нейрон (предсказание цены)
- Сохранение/загрузка весов в `.pth` файл

### 2. Функция обучения `train_model()`
- Разделить данные на train/val/test (70/15/15)
- Нормализация признаков (StandardScaler)
- Loss: MSE, Optimizer: Adam (lr=0.001)
- Обучение с логированием loss по эпохам
- Сохранение модели + статистики нормализации

### 3. Функция прогнозирования `predict()`
- Загрузка модели + статистики
- Принимает CSV с лагами или отдельные значения
- Вывод предсказанной цены + метрики (MAE, RMSE, MAPE)

### 4. CLI-интерфейс
```
python main.py train [epochs]    — обучить модель (по умолч. 50 эпох)
python main.py predict <data.csv> — прогноз по файлу
python main.py predict-lag <lag1> <lag2> ... — прогноз по 6 значениям
```

### 5. Визуализация (опционально)
- График: реальные vs предсказанные цены на test-сете
- Сохранение в `prediction_plot.png`
