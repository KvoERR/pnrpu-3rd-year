# Plan: Fix Z-shift projection and add Y-axis rotation

## Problem
1. When shifting by Z, the projected 2D position of points should remain unchanged (compensate X/Y inversely to the perspective scale).
2. Rotation around the Y-axis should change the projected position (since it changes both X and Z).

## Changes

### 1. `ViewModels/MainViewModel.cs`

**a) Add `RotateY` property and `RotateYCommand`:**
- Private field `_rotateY`
- Public property `RotateY` with INPC
- Public command `RotateYCommand`
- Method `RotateYByAngle(object parameter)` — rotates points around Y-axis through the transform center:
  ```
  x' = x * cos(θ) + z * sin(θ)
  z' = -x * sin(θ) + z * cos(θ)
  y' = y  (unchanged)
  ```
  All relative to the transform center.

**b) Fix `MoveZByAmount` — compensate X/Y so projection stays constant:**

Current projection:
```
scale = FocalLength / (FocalLength + z)
projectedX = centerX + (x - centerX) * scale
projectedY = centerY + (y - centerY) * scale
```

To keep `projectedX` and `projectedY` unchanged after Z changes from `z_old` to `z_new`:
```
scale_old = FocalLength / (FocalLength + z_old)
scale_new = FocalLength / (FocalLength + z_new)
x_new = centerX + (x_old - centerX) * scale_old / scale_new
y_new = centerY + (y_old - centerY) * scale_old / scale_new
```

This ensures the 2D screen position is invariant under Z translation.
