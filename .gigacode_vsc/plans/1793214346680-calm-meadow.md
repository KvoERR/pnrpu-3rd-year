# Plan: Заглушки для GetForm и ShowForm

## Контекст

Проект — WPF-банкомат (KostyaBank). В главном меню есть две кнопки:
- **"Узнать баланс"** → должна открывать форму баланса (ShowForm)
- **"Снять наличные"** → должна открывать форму снятия (GetForm)

**Текущее состояние:**
- `MainMenuViewModel` — главное меню, обе кнопки показывают MessageBox "в разработке"
- `GetFormViewModel` — существует, но по сути копия MainMenuViewModel (не форма снятия)
- `ShowFormViewModel` — не существует
- `AppViewModel.ShowGetForm` — ошибочно создаёт `MainMenuViewModel` вместо `GetFormViewModel`
- `AppViewModel.ShowShowForm` — не существует
- XAML-представления для обеих форм отсутствуют

## Что нужно сделать

### 1. Создать `ShowFormViewModel.cs`
ViewModel для отображения баланса карты:
- Свойства: `CardNumber`, `MaskedCardNumber`, `HolderName`, `Balance` (как в MainMenuViewModel)
- `BackCommand` — возврат в главное меню (вызывает `_appViewModel.ShowMainMenu(_card)`)
- Метод `ShowSection` — заглушка, показывает MessageBox с инфо о балансе

### 2. Переделать `GetFormViewModel.cs`
Превратить в форму снятия наличных:
- Свойство `WithdrawAmount` (string) — ввод суммы пользователем
- Свойство `CanWithdraw` (bool) — можно ли снять (сумма валидна и <= баланса)
- `WithdrawCommand` — заглушка: валидация суммы, MessageBox "в разработке"
- `BackCommand` — возврат в главное меню
- Удалить дублирующиеся `_showCommand` и `_getCommand` (это уже функции MainMenuViewModel)

### 3. Обновить `AppViewModel.cs`
- Исправить `ShowGetForm(Card card)` — создавать `GetFormViewModel`
- Добавить `ShowShowForm(Card card)` — создавать `ShowFormViewModel`
- Добавить `ShowMainMenu(Card card)` (если нет) — создавать `MainMenuViewModel`

### 4. Создать `Views/ShowFormView.xaml`
XAML-представление для ShowFormViewModel:
- Карточка с информацией: номер карты (маскированный), имя держателя, баланс
- Кнопка "Назад" для возврата в меню
- Стиль в тон проекту (зелёная тема #1B5E20)

### 5. Создать `Views/GetFormView.xaml`
XAML-представление для GetFormViewModel:
- Поле ввода суммы (`TextBox`) для `WithdrawAmount`
- Кнопка "Снять" для `WithdrawCommand`
- Кнопка "Назад" для `BackCommand`
- Стиль в тон проекту

### 6. Зарегистрировать DataTemplates в `Views/MainWindow.xaml`
Добавить шаблоны для новых ViewModel → View:
```xml
<DataTemplate DataType="{x:Type vm:ShowFormViewModel}">
    <views:ShowFormView />
</DataTemplate>
<DataTemplate DataType="{x:Type vm:GetFormViewModel}">
    <views:GetFormView />
</DataTemplate>
```
