# Рефакторинг: одно окно с переключением контента

## Цель
Заменить навигацию через несколько окон на одно `MainWindow` с `ContentControl`, который меняет содержимое при навигации.

## Текущее состояние

```
App.xaml → StartupUri="Views/CardEntryWindow.xaml" (Window)
  ├─ CardEntryWindow (Window) + CardEntryViewModel
  │    └─ Login → NavigationService.ShowMainMenu() → Views/MainWindow (Window)
  │         └─ MainMenuViewModel (баланс, пополнение, снятие...)
  │
  └─ Нажатие 'S' → NavigationService.ShowServiceView() → Views/ServiceView (Window)
       └─ ServiceViewModel
```

## Целевое состояние

```
App.xaml → OnStartup → MainWindow (одно окно) + AppViewModel
  └─ ContentControl Content={Binding CurrentView}
       ├─ DataTemplate CardEntryViewModel → CardEntryView (UserControl)
       ├─ DataTemplate MainMenuViewModel → MainMenuView (UserControl)
       └─ DataTemplate ServiceViewModel → ServiceView (UserControl)
```

## Этапы

### Этап 1. Конвертация Window → UserControl

**1.1. Views/CardEntryWindow.xaml → Views/CardEntryView.xaml (UserControl)**
- Заменить `<Window ...>` на `<UserControl ...>`
- Удалить `<Window.DataContext>` (DataContext будет задаваться через DataTemplate)
- Удалить `xmlns:vm="..."` (не нужен без DataContext в XAML)
- Оставить Grid с содержимым

**1.2. Views/CardEntryWindow.xaml.cs → Views/CardEntryView.xaml.cs**
- Заменить `: Window` на `: UserControl`
- Удалить `CardEntryWindow()` конструктор
- Сохранить методы валидации (PreviewTextInput, Pasting)
- Фокус на TextBox — через `Loaded` event или Trigger

**1.3. Views/ServiceView.xaml → Views/ServiceView.xaml (UserControl)**
- Заменить `<Window ...>` на `<UserControl ...>`
- Удалить `Title`, `Height`, `Width` (задаются в MainWindow)
- Удалить `<Window.DataContext>`

**1.4. Views/ServiceView.xaml.cs → Views/ServiceView.xaml.cs**
- Заменить `: Window` на `: UserControl`
- Удалить конструктор

**1.5. Views/MainWindow.xaml — переписать**
- Удалить всё содержимое (header, menu buttons)
- Заменить на `<ContentControl Content="{Binding CurrentView}"/>`
- Добавить `Window.Resources` с `DataTemplate` для каждого ViewModel
- Добавить `xmlns:vm` и `xmlns:views` namespace'ы

**1.6. Views/MainWindow.xaml.cs — упростить**
- Конструктор без параметров (DataContext задаётся в App.xaml.cs)

### Этап 2. Создание AppViewModel

**ViewModels/AppViewModel.cs**
- Наследуется от `BaseViewModel`
- Свойство `object CurrentView` — текущий View
- Методы:
  - `ShowCardEntry()` → `CurrentView = new CardEntryViewModel()`
  - `ShowMainMenu(Card card)` → `CurrentView = new MainMenuViewModel(card)`
  - `ShowServiceView()` → `CurrentView = new ServiceViewModel()`
  - `ExitApp()` → `Application.Current.Shutdown()`
- В конструкторе: `CurrentView = new CardEntryViewModel()`

### Этап 3. Обновление ViewModel для навигации

**3.1. ViewModels/CardEntryViewModel.cs**
- Убрать `new Computer()` без аргументов (если нет конструктора по умолчанию)

- В `ExecuteLogin()`: вызвать `appViewModel.ShowMainMenu(card)` вместо `NavigationService`
- Убрать `new NavigationService()` и `navigationService.ShowMainMenu(card)`

**3.2. ViewModels/MainMenuViewModel.cs**

**3.3. ViewModels/ServiceViewModel.cs**
- Добавить ссылку на `AppViewModel`

### Этап 4. Обновление App.xaml.cs

  ```csharp
  mainWindow.DataContext = appViewModel;
  mainWindow.Show();
  Application.Current.MainWindow = mainWindow;
  ```
- Убрать обработчик `App_PreviewKeyDown` для 'S' (перенести в MainWindow.xaml.cs)

### Этап 5. Обработка клавиши 'S' в MainWindow

- Добавить `Loaded` event handler

## Ключевые моменты

1. **DataContext в MainWindow** задаётся в `App.xaml.cs`, а не в XAML
2. **DataTemplate DataType** связывает ViewModel → View автоматически
3. **NavigationService** больше не нужен — навигация через `AppViewModel`
4. **'S' для сервиса** — через `PreviewKeyDown` на MainWindow
5. **CardEntryView** не создаёт свой DataContext — берёт из `CurrentView`

## Потенциальные проблемы

| Проблема | Решение |
|----------|---------|
| DataTemplate не срабатывает | Убедиться, что `DataType` совпадает с полным namespace |
| Фокус на TextBox | Использовать `FocusManager.FocusedElement` или `Loaded` event |
| Excel COM-поток | Убедиться, что `Computer` работает в UI-потоке (WPF по умолчанию) |
| Старые файлы | Удалить `MainWindow.xaml` и `CardEntryWindow.xaml` из проекта |
