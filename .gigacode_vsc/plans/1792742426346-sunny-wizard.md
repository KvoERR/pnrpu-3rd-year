# Plan: Bank Application — Card Code Entry Window

## Goal
Create a WPF bank application with a first window for entering a 16-digit card number via keyboard, followed by a main menu screen.

## Architecture
- **Framework:** WPF (.NET 8.0)
- **Pattern:** Code-behind for simplicity (MVVM not needed for this scope)
- **Navigation:** `Window`-based navigation (CardEntryWindow → MainWindow)

## Implementation Steps

### 1. Models
- **File:** `Models/Card.cs`
- Simple POCO to hold card data: `CardNumber` (string), `IsValid()` method (Luhn algorithm)

### 2. Views — Card Entry Window
- **File:** `Views/CardEntryWindow.xaml`
- Clean, modern UI with:
  - Bank logo/name at top
  - Title "Введите номер карты"
  - TextBox for 16-digit card number (masked input, digits only)
  - "Войти" button (enabled only when 16 digits entered)
  - Error message label for invalid input

- **File:** `Views/CardEntryWindow.xaml.cs`
  - Input validation: digits only, max 16 chars
  - Button click → validate card number (Luhn check)
  - On success → open MainWindow, close CardEntryWindow
  - On failure → show error message

### 3. Views — Main Menu Window
- **File:** `Views/MainWindow.xaml`
  - Bank branding header
  - Menu buttons (grid layout):
    - "Баланс"
    - "Пополнить"
    - "Снять"
    - "История"
    - "Выход"
  - Card number display (masked: `**** **** **** 1234`)

- **File:** `Views/MainWindow.xaml.cs`
  - Accept card number in constructor
  - Display masked card number
  - Button handlers (placeholders for now)

### 4. App Entry Point
- **File:** `App.xaml`
  - Change `StartupUri` to `Views/CardEntryWindow.xaml`

### 5. Styling
- Add a shared `Styles.xaml` in `Converters/` or inline in App.xaml
- Modern, clean design with bank-appropriate colors (dark blue/green theme)
- Consistent button styles, text styles

## Key Details
- Card input: TextBox with `PreviewTextInput` to allow only digits, `MaxLength="16"`
- Luhn algorithm for card validation
- Masked display in main menu: show only last 4 digits
- Window transitions: CardEntryWindow opens first, on valid card → MainWindow opens, CardEntryWindow closes
