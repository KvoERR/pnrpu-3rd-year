def load_coffee(path):
    """Загружает CSV, возвращает (dates, prices)."""
    df = pd.read_csv(path, sep=',', encoding='utf-8-sig')
    df.columns = ['date', 'price', 'open', 'high', 'low', 'volume', 'change_pct']
    
    # Парсим числа

### 2. Новая функция `make_lags(prices, lags)`
**Убирает** `make_lag_dataset` (работала с DataFrame).
**Добавляет:**
```python
def make_lags(prices, lags=(1, 2, 3, 5, 10, 22)):
    """
    Из списка цен создаёт два списка:
      - lag_list: [[lag1, lag2, ...], [...], ...]
      - price_list: [price, price, ...]
    """
    max_lag = max(lags)
    lag_list = []
    price_list = []
    
    for i in range(max_lag, len(prices)):
        lag_row = [prices[i - lag] for lag in lags]
        lag_list.append(lag_row)
        price_list.append(prices[i])
    
    return lag_list, price_list
```

### 4. `get_lags(path, lags)`
**Было:** пытался работать с DataFrame
**Станет:**
```python
def get_lags(path='data.csv', lags=(1, 2, 3, 5, 10, 22)):
    """Возвращает список актуальных лагов для предсказания."""
    _, prices = load_coffee(path)
    last_prices = prices[-max(lags):]
    return [last_prices[-lag] for lag in lags]
```
