# План: Множественное выделение фигур

## Цель
- Выделение фигур при клике на холсте
- Возможность выделения нескольких фигур (Ctrl+Click или Shift+Click)
- Визуальная подсветка всех выделенных фигур

## Изменения

### 1. MainViewModel.cs
- Добавить `ObservableCollection<ShapeViewModel> SelectedShapes` — коллекция выделенных фигур
- Заменить `SelectedShape` на логику с коллекцией:
  - Сохранить `SelectedShape` как `SelectedShapes.FirstOrDefault()` для обратной совместимости с UI свойств
- Добавить команду `ToggleShapeSelection(ShapeViewModel shape)` — переключает выделение конкретной фигуры
- Обновить `DeselectAll` — очищает `SelectedShapes`
- Обновить `DeleteShape` — удаляет **все** выделенные фигуры
- Обновить команды трансформаций (Move, Rotate, Scale) — применяют ко **всем** выделенным фигурам
- Обновить `AddShape` — не выделять автоматически (или выделять новую, если Ctrl не нажат)

### 2. MainWindow.xaml
- Добавить `MouseBinding` на Canvas для `LeftMouse` действия → `ToggleSelectionCommand`
- Убрать `LeftClick` binding (который сбрасывает выделение), заменить на:
  - `LeftClick` на пустом месте → `DeselectAll`
  - `LeftClick` на фигуре → `ToggleShapeSelection` (через EventTrigger или AttachedProperty)

**Подход:** Использовать `InputBindings` на Canvas для клика по пустому месту (DeselectAll), а для клика по фигуре — использовать `PreviewMouseLeftButtonDown` на элементе фигуры с `Command` через `Interaction.Triggers` или просто обработать в ShapeViewModel.

**Лучший подход:** Добавить на каждый элемент фигуры `InputBindings` с `MouseBinding` на `LeftClick`, который вызывает команду `ToggleSelectionCommand` с параметром-ShapeViewModel.

### 3. ShapeTemplate в XAML
- Добавить `InputBindings` в DataTemplate:
  ```xml
  <Canvas.InputBindings>
      <MouseBinding MouseAction="LeftClick" 
                    Command="{Binding DataContext.ToggleSelectionCommand, RelativeSource={RelativeSource AncestorType=ItemsControl}}"
                    CommandParameter="{Binding}"/>
  </Canvas.InputBindings>
  ```
- Убрать `MouseBinding` на Canvas (deselect) — вместо этого добавить отдельный обработчик или `Border` с прозрачностью на фон Canvas

### 4. Детали реализации ToggleSelectionCommand
```
ToggleShapeSelection(ShapeViewModel shape):
    if (shape == null) return;
    if (SelectedShapes.Contains(shape))
        SelectedShapes.Remove(shape);
    else
        SelectedShapes.Add(shape);
    OnPropertyChanged(nameof(SelectedShape)); // для свойств в UI
```
