# План исправления поворота и отображения угла

## Проблема
1. **Поворот не работает** — метод `Rotate()` в `Shape.cs` использует локальный центр вместо глобального и неправильно.compose матрицы
2. **Угол не отображается** — `NotifyTransformChanged()` не обновляет свойства `RotationAngle`/`ScaleFactor` для UI

## Причины

### Rotate() — Shape.cs:89-113
- `GetLocalCenter()` возвращает центр в локальных координатах, но translate должен быть вокруг глобального центра
- Ручная декомпозиция матрицы на angle/scale и последующее пересборка ошибочна
- `Matrix.Multiply(result, rotScale)` — неверный порядок умножения

### NotifyTransformChanged() — ShapeViewModel.cs:198-204
- Не вызывает `OnPropertyChanged(nameof(RotationAngle))` — TextBox на правой панели не обновляется
- Не вызывает `OnPropertyChanged(nameof(ScaleFactor))` — аналогично

## Исправления

### 1. `Shape.cs` — метод `Rotate(double angleDegrees)` (строки 89-113)

Заменить на корректную композицию матриц вокруг глобального центра:

```csharp
public void Rotate(double angleDegrees)
{
    var center = GetCenter(); // Глобальный центр

    var matrix = TransformMatrix;
    var t1 = new Matrix();
    t1.Translate(-center.X, -center.Y);
    var r = new Matrix();
    r.Rotate(angleDegrees);
    var t2 = new Matrix();
    t2.Translate(center.X, center.Y);

    matrix = Matrix.Multiply(matrix, t1);
    matrix = Matrix.Multiply(matrix, r);
    matrix = Matrix.Multiply(matrix, t2);

    TransformMatrix = matrix;
}
```

Логика: `M' = M × Translate(-C) × Rotate(angle) × Translate(C)`
- `Translate(-C)` — сдвиг центра в начало координат
- `Rotate(angle)` — поворот
- `Translate(C)` — сдвиг центра обратно

### 2. `Shape.cs` — метод `Scale(double scale)` (строки 116-138)

Аналогично, использовать глобальный центр:

```csharp
public void Scale(double scale)
{
    var center = GetCenter(); // Глобальный центр

    var matrix = TransformMatrix;
    var t1 = new Matrix();
    t1.Translate(-center.X, -center.Y);
    var s = new Matrix();
    s.Scale(scale, scale);
    var t2 = new Matrix();
    t2.Translate(center.X, center.Y);

    matrix = Matrix.Multiply(matrix, t1);
    matrix = Matrix.Multiply(matrix, s);
    matrix = Matrix.Multiply(matrix, t2);

    TransformMatrix = matrix;
}
```

### 3. `ShapeViewModel.cs` — метод `NotifyTransformChanged()` (строки 198-204)

Добавить обновление вычисляемых свойств:

```csharp
public void NotifyTransformChanged()
{
    OnPropertyChanged(nameof(TransformedPoints));
    OnPropertyChanged(nameof(ClosedPoints));
    OnPropertyChanged(nameof(Bounds));
    OnPropertyChanged(nameof(DisplayName));
    OnPropertyChanged(nameof(RotationAngle));  // <-- добавить
    OnPropertyChanged(nameof(ScaleFactor));     // <-- добавить
}
```
