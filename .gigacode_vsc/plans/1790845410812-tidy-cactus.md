# План: Разделение GUI на вкладки "Шифровка" и "Расшифровка"

## Цель
Заменить текущую плоскую раскладку на `ttk.Notebook` с двумя вкладками.

## Изменения в `gui.py`

1. **Добавить `ttk.Notebook`** с двумя вкладками:
   - `"Шифрование"` — для шифровки
   - `"Расшифровка"` — для расшифровки

2. **Общие элементы** (p, q, генерация, импорт, сохранение, инфо-лейбл) разместить **над вкладками**, чтобы не дублировать.

3. **Вкладка "Шифрование"**:
   - Метка + Text для исходного текста
   - Кнопка "Зашифровать"
   - Метка + Text для результата

4. **Вкладка "Расшифровка"**:
   - Метка + Text для зашифрованного текста (числа через запятую)
   - Кнопка "Расшифровать"
   - Метка + Text для результата

5. **Удалить** старые кнопки шифрования/расшифровки из общего фрейма (строки 42–46).

6. **Обновить** методы `encrypt()` и `decrypt()`, чтобы они брали текст из соответствующих виджетов на каждой вкладке.

## Структура нового layout

```
[Текст (общий)]
[Импорт из файла]
[p] [q] [Генерировать]
[Notebook]
  | Шифрование | Расшифровка |
  |------------|-------------|
  | Text       | Text        |
  | [Зашифровать] | [Расшифровать] |
  | Result     | Result      |
[Результат (общий)]
[Info]
```

Или проще — результат тоже на каждой вкладке свой, а общий результат убрать.
