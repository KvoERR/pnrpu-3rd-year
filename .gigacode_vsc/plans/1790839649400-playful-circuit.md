# План: Реализация шифрования RSA

## Цель
Заменить текущую реализацию столбцового транпозиционного шифра на полноценный алгоритм RSA согласно описанному пользователем алгоритму.

## Что нужно сделать

### 1. Обновить `main.py` — ядро RSA

Заменить содержимое `main.py` на реализацию RSA:

**Функции для реализации:**

1. **`extended_gcd(a, b)`** — расширенный алгоритм Евклида, возвращает `(gcd, x, y)` такие что `a*x + b*y = gcd`. Нужен для шага 4 (поиск d).

2. **`mod_inverse(e, phi)`** — находит обратное число `d` по модулю `phi = (p-1)*(q-1)` через `extended_gcd`. Решает уравнение `e*d ≡ 1 (mod phi)`.

3. **`generate_keys(p, q)`** — генерация ключей по шагам 1–6:
   - `n = p * q`
   - `phi = (p - 1) * (q - 1)`
   - **Важно: e < n** (из описания алгоритма). Подбираем e из списка `[3, 5, 7, 11, 13, 17, 65537]` — берём первое, для которого `e < n` и `gcd(e, phi) == 1`. Для малых p, q (n < 65537) автоматически возьмётся меньшее e.
   - `d = mod_inverse(e, phi)`
   - Возвращаем `(e, n, d)`

4. **`text_to_blocks(text, n)`** — преобразование строки в блоки чисел:
   - `k = floor(log2(n))` бит на блок (из описания: k = [log₂(n)])
   - `block_size = max(1, k // 8)` байт на блок
   - Если блок value >= n — уменьшаем block_size пока не влезет
   - Каждый блок текста → bytes → int
   - Возвращаем список целых чисел `m_i`

5. **`blocks_to_text(blocks)`** — обратное преобразование: int → bytes → строка

6. **`encrypt(text, e, n)`** — шифрование:
   - Разбить текст на блоки
   - Для каждого блока: `c_i = pow(m_i, e, n)`
   - Вернуть список зашифрованных чисел

7. **`decrypt(ciphertext, d, n)`** — расшифровка:
   - Для каждого блока: `m_i = pow(c_i, d, n)`
   - Собрать обратно в текст

### 2. Обновить `gui.py` — интерфейс

Подстроить GUI под новый API:

- Поля `p` и `q` — пользователь вводит простые числа
- При нажатии **"Зашифровать"**:
  - Вычислить ключи через `generate_keys(p, q)`
  - Зашифровать текст через `encrypt(text, e, n)`
  - Показать результат (список чисел или hex-строку)
- При нажатии **"Расшифровать"**:
  - Ввести зашифрованные числа (через запятую или пробел)
  - Вычислить ключи через `generate_keys(p, q)`
  - Расшифровать через `decrypt(ciphertext, d, n)`
  - Показать исходный текст

**Формат вывода:**
- Зашифрованный текст — числа через запятую (например: `12345, 67890, 11111`)
- Расшифровка — ввод чисел через запятую, вывод — исходный текст

### 3. Удалить неиспользуемый код

- Удалить `_validate`, `encrypt`/`decrypt` столбцового шифра из `main.py`
